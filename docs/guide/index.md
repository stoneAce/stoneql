# User guide

StoneQL is a compact, phpMyAdmin-inspired database client for macOS, Windows and Linux. The desktop app connects live to your MySQL, MariaDB and PostgreSQL servers, directly or through an SSH tunnel (SSH tunnels on macOS and Linux only for now).

Follow these pages in order to get from a download to a working connection:

1. [Download](./download.md) StoneQL and check that the file is intact.
2. [Install](./install.md) it and get past the first-launch warning.
3. [Connect to a database](./connect.md).

Then, when you are connected:

- [Browse and edit tables](./browse-and-edit.md): explore databases, page through rows, edit data and change table structure.
- [Run SQL](./run-sql.md): run queries and scripts, use transactions and read the results.
- [Import and export](./import-export.md): back up tables and databases, load SQL and CSV files.

If something goes wrong, see [Troubleshooting](./troubleshooting.md). [What's in this release](./beta.md) lists what works today and what is not available yet.

::: warning Real databases
StoneQL makes real changes to real databases. Keep backups, use an account with only the privileges you need, and verify important changes on the server.
:::
